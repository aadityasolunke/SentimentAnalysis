# SentimentAnalysis
# 📝 Sentiment Review App (VADER-based)

This is a simple Streamlit web app that analyzes the sentiment of user-written product reviews using the VADER sentiment analysis model from NLTK.

## 🚀 Features

- Enter product reviews and get instant sentiment (Positive, Negative, Neutral)
- Visual sentiment scores (pos/neu/neg/compound)
- Built with Streamlit, NLTK, and Pandas
- Fully local (no data saved)
- Ready to deploy on Streamlit Cloud

## 🛠️ Technologies Used

- Python
- Streamlit
- NLTK (VADER)
- Pandas
